Проверить статус:

  kubectl get pods,svc -n {{ .Release.Namespace }} -l app.kubernetes.io/part-of=ecommerce-infra
  kubectl get pvc -n {{ .Release.Namespace }}

Дождаться готовности перед установкой app-чарта:

  kubectl wait --for=condition=ready pod \
    -l app.kubernetes.io/part-of=ecommerce-infra \
    -n {{ .Release.Namespace }} --timeout=600s

Дальше:

  helm install ecommerce ./deploy/helm/ecommerce-shop -n {{ .Release.Namespace }} -f ./deploy/helm/ecommerce-shop/values-dev.yaml
